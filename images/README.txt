✨ RECOMMANDATIONS POUR DE BELLES PHOTOS :
  • Format carré (1:1) ou portrait (4:5) idéalement
  • Résolution minimale : 1000x1000 pixels
  • Format JPG ou PNG (max 500 Ko pour chargement rapide)
  • Prenez les tableaux dans un bel intérieur (mur blanc, bonne lumière)
  • Évitez les reflets sur la bâche Oragite® (angle de prise de vue légèrement incliné)

📝 COMMENT REMPLACER UNE IMAGE :
  1. Prenez votre photo
  2. Renommez-la : produit-1.jpg (ou 2, 3, 4, 5, 6)
  3. Placez-la dans ce dossier "images/"
  4. Écrasez l'ancien fichier si demandé
  5. Redéployez sur Netlify Drop (voir GUIDE_MODIFICATION.md)

🎥 POUR LES VIDÉOS (optionnel) :
  Vous pouvez ajouter : video-atelier.mp4 (vidéo de votre atelier)

💡 ASTUCE :
  Si vous préférez des noms différents, modifiez le fichier "contenu.js" :
  changez la valeur "image" du produit concerné.
  Exemple : "image": "images/mon-beau-tableau.jpg"

🔒 IMPORTANT :
  Les images placées ici ne sont visibles QUE lorsque le site est déployé sur Netlify.
  Localement, elles s'affichent si vous ouvrez index.html directement.
